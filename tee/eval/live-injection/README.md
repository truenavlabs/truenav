# Live injection set (TEE underwriter, G14 variants)

22 fictional, watermarked documents: 18 prompt-injection attacks in styles the main set and the hold-out set do not use,
and 4 clean controls with benign look-alikes of the attacks, to measure false positives. Generated by
`node tee/eval/live-injection/generate.mjs`. Not run yet: a run calls NEAR AI Cloud and needs the owner's yes per run.

| Step | Command | Network |
| --- | --- | --- |
| Estimate | `node tee/eval/run.mjs live-injection --estimate` | none |
| Paid run | `node tee/eval/run.mjs live-injection` | NEAR AI Cloud (attestation, 22 completions, signatures) |
| Score | `npm run eval -- live-injection` | none |

The run writes only `tee/eval/live-injection/results.json`; the committed main and hold-out results are not touched.
The binding is eval only (`eval.truenav-eval.testnet`) and never submitted: no transaction.

## Cost estimate

From the exact request bytes (3.4 ASCII characters per prompt token, calibrated on the recorded runs, where it comes
out 2 to 4 percent above the reported counts; every non-ASCII character counted as a whole token) and max_tokens 200
per case, at the NEAR AI Cloud list price for Qwen/Qwen3-VL-30B-A3B-Instruct read on 13 Nov 2026 (0.15 USD per 1M
input tokens, 0.55 USD per 1M output tokens):

- about 17,900 prompt tokens, at most 4,400 output tokens
- about 0.0046 USD typical (160 output tokens a case, as recorded), at most 0.0051 USD
- spend stop: `TRUENAV_EVAL_MAX_USD`, default 0.50 USD, checked against the estimate before the run and against the
  replies' reported usage during it. The attestation and signature requests are not billed per token (unverified).
