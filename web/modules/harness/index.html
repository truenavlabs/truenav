Limits

  • TrueNav informs only. The registry makes no cross-contract call, sends no NEAR, and its pledge tokens cannot be transferred. (README, How it works, step 5)
  • Testnet and fictional data only. TrueRange assumes independent defaults. (README, Security and limits)
  • Pledges, verdicts, attempts, alerts and certificates are public chain state. A refused pledge returns already pledged elsewhere without naming the holder. (README, Security and limits)
  • The certificate signer is a test key, not a TEE key. Anyone can recompute the numbers. (README, Roles and keys)
  • The contract does not verify the hardware quote. The registrar checks attestation off chain. (README, Roles and keys)
  • A TEE proves which code ran, not that the model's judgment is right. (README, Security and limits)

How to verify

  1. Re-read views with the NEAR CLI or a JSON-RPC query to registry.tnlab-368aa2.testnet. Methods include get_fund, get_latest_certificate, get_lock, nft_token.
  2. npm run chain:read
  3. npm run verify:attestation
  4. Recompute each manifest sha256 from the JSON section with sorted keys.
